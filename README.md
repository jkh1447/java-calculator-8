# java-calculator-precourse


## 문자열 덧셈 계산기

입력된 문자를 더하는 계산기


## 구현할 기능 목록

- [x] 사용자의 입력을 받는다.
- [x] 입력에 대한 예외처리.
  * 예외처리를 해야하는 케이스:
    * "숫자"나 "//~\n" 로 문자열이 시작하지 않는 경우.
    * //와 \n 사이에 문자열이 없는 경우.
    * 커스텀 구분자나 기본 구분자가 포함되지 않는 경우.
    * 음수가 입력되는 경우.
- [x] 입력한 문자열에서 커스텀 구분자 부분과 숫자 부분을 분리한다. 
- [x] 구분자를 기준으로 분리하여 배열로 만든다.
- [x] 배열의 각 원소를 더한다.
- [ ] 더한 값을 출력한다.
